# Secret Santa — React App

Simple React app (Vite) providing pages for a Secret Santa event.

Run locally (PowerShell):

```powershell
cd "c:\Users\ase84\personal\secret-santa"
npm install
npm run dev
```

Pages included:
- Landing / Sign up
- Login
- Onboarding
- Admin: Draw Child
- Dashboard

Data is stored in `localStorage` for this prototype.
